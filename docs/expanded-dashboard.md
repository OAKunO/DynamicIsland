# 展开面板自适应分页

功能较少时继续并排显示。宽度超过预算时，优先合并宽度接近的卡片，直到整个面板能放下：电脑、手机、录屏通常共用窄栏；工作台、音乐、计时等宽卡片共用宽栏。备忘录在空间允许时保持独立。

默认预算最多 1000 点；实际窗口还限制为所在屏幕宽度的 85%，并保留屏幕边缘空间。内容区保持原有的 256 点高度，分页切换栏单独放在下方，额外占 26 点，出现分页时总高度为 282 点；无需分页时仍为 256 点。7 个模块全部开启时，默认从约 1916 点收至约 868 点，保留三栏。

每个合并栏底部显示模块名称及左右箭头，可点击名称、箭头，或在该栏用触控板横向滑动切换。鼠标也可以在底部切换栏左右拖动。纵向滚动仍交给待办列表、工作台和详情列表；单次手势只切换一页，惯性滚动不会连续翻页。

切换时保留卡片实例，刚完成的待办划线和设备详情状态不会因为切页而重置。非当前页不接收点击，也不暴露给无障碍导航。离开计时或录屏页时收起对应的设置面板。

AI 工作台压缩任务列表与打开按钮之间的留白，保持任务行原有字号与高度，默认可完整显示三条任务；打开按钮采用更紧凑的垂直内边距，并下移至距内容区底部 6 点。可通过分页渲染脚本查看三条任务的内存样例。

窗口、长度设置和内容布局共用 `IslandExpandedLayout`。展开页面采用新的组合长度键，紧凑模式偏好保留；长度设置的上限同样遵守屏幕预算，不能通过历史超长配置再次撑满屏幕。计时完成提醒、解锁问候和录屏独占展示沿用其原有优先级。

## 验证

- `zsh scripts/run-paging-tests.sh`：全部 128 种模块组合在不同宽度下的可达性、唯一性、屏幕适配、底栏高度和手势判定。
- `zsh scripts/run-length-tests.sh`：状态目录、宽度校准、迁移和持久化。
- `zsh scripts/run-display-tests.sh`：展示开关、任务过滤与布局。
- `zsh scripts/run-notes-tests.sh`：待办状态与跨进程持久化。
- `zsh scripts/render-paging-ui.sh`：真实 SwiftUI 离屏渲染；检查 256 点内容区不与底栏相交、计时结束时间完整、原生鼠标事件切页、完成后的撤销及备忘录确认删除。

渲染产物位于 `.derivedData/PagingUI/screenshots/`。所有检查使用内存样例、临时目录和随机 UserDefaults suite，不修改正式备忘录，也不捕获用户屏幕。触控板硬件输入仍需人工验证；水平事件判定与纵向／惯性滚动保护由自动检查覆盖。

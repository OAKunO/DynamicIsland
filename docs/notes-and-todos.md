# 备忘录与待办

备忘录、待办与解锁摘要共用本地存储，不依赖系统备忘录或云服务。

## 使用

- 展开灵动岛，备忘录在原有模块右侧成列，默认显示置顶备忘录与含未完成待办的记录。功能过多时按宽度合并分页，卡片内容高度保持不变，分页切换栏单独增加在内容下方。
- “全部”可以查看普通文字、完成后的记录；“+”新建。点击正文或待办文字进入完整编辑窗口。
- 同一条记录支持任意正文与多条待办。勾选后立即保存完成状态，当前展开期间待办留在原位显示灰色划线，可再次点击撤销；即使完成最后一项，整条备忘录也会暂时保留。收起灵动岛再展开后，已完成事项归入默认折叠的“已完成”；非置顶且没有未完成待办的记录移出“置顶与待办”，仍可在“全部”中查看。正文始终保留。
- 图钉控制置顶。编辑器支持修改正文、增加或移除待办、置顶、保存（Command-S）以及确认删除。
- 卡片标题右侧的垃圾桶删除整条备忘录及其中所有待办，点击后在卡片内选择“删除”或“取消”。每条待办右侧的垃圾桶直接删除该项，未完成、刚勾选及展开后的已完成项目均可删除；正文和其他待办保留。删除纯待办记录中的最后一项时一并移除空记录。卡片删除立即保存，编辑器中的删除仍需点击“保存”。
- 编辑器采用显式保存。取消放弃当前草稿；关闭窗口或锁屏会保留内存中的草稿，再次打开可继续。退出应用前仍需保存草稿。
- 解锁问候展示最多两条置顶／未完成摘要，单条最多 64 个字符加省略号；点击打开完整记录。列表与摘要截断不会改变保存的原文。
- 展示设置中可独立隐藏“备忘录与待办”。计时完成提示及录屏独占展示沿用原优先级。

## 本地保存与隐私

正式应用保存到 `~/Library/Application Support/DynamicIsland/memos-v1.json`，使用版本化 JSON 和原子替换。保存失败时显示错误，内存不会假装已保存；读取损坏或未知版本文件时保留原文件并拒绝覆盖。

不读取 Apple Notes，不新增模型、云服务或同步依赖。只有正式 AppDelegate 构造本地文件存储；预览、测试默认使用内存或临时目录。

监听现有会话激活／屏幕解锁通知，并补充屏幕锁定及会话失活通知。解锁事件先检查当前会话是否位于控制台且未锁定，再更新状态和显示问候；重复事件在两秒内合并。锁定时清空当前及排队问候、收起岛、覆盖可视内容并隐藏编辑窗口，锁定期间预览问候也被拒绝。正常启动时同样检查会话状态。

编辑草稿保存时合并字段变化，保留草稿打开后在快速卡片上完成／撤销待办或置顶的新状态。

## 验证

- `zsh scripts/run-notes-tests.sh`：增改、完成／撤销、删除、置顶、Unicode、摘要截断、错误保护、草稿冲突合并，以及独立进程间的持久化恢复。
- `zsh scripts/run-session-tests.sh`：启动时检查、提前／缺失的会话通知、睡眠唤醒与锁定隐私保护。
- `zsh scripts/run-paging-tests.sh`：模块组合、宽度预算与切页可达性。
- `zsh scripts/render-notes-ui.sh`：使用内存样例渲染展开区、空态、编辑器、问候摘要和模拟锁定覆盖。
- `zsh scripts/render-paging-ui.sh`：切页后保留待办状态、确认删除及底栏布局。

测试使用内存样例、随机 UserDefaults suite 或临时目录，不写入正式备忘录。生成截图位于 `.derivedData/NotesUI/screenshots/` 和 `.derivedData/PagingUI/screenshots/`，无需提交。

渲染脚本需要本地 Xcode 编译插件及 AppKit 环境。受限沙盒可能阻止 SwiftUI macro plugin；这些检查不需要开启屏幕录制、辅助功能或 Apple Notes 权限。

真实应用中的键盘输入、系统锁屏／解锁通知时序和触控板输入需要人工验收。自动检查与离屏渲染不代表真实系统事件的端到端验收。

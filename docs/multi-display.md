# 多屏灵动岛

1.1 版支持多个显示器。应用启动时读取 macOS 的可用屏幕列表，并监听显示器连接、断开、排列和缩放变化；每个屏幕按自己的坐标、尺寸和刘海安全区域布局，无需用户填写显示器名称或分辨率。

## 显示范围

「设置 → 功能开关 → 副屏显示灵动岛」默认开启。关闭后只保留系统主屏上的窗口，选择立即生效并保存到本机偏好，重启应用后继续使用。

系统主屏按 `NSScreen.screens` 的第一项确定，不会随键盘焦点或鼠标位置改变。关闭副屏显示后，修改系统主屏或断开原主屏时，窗口跟随 macOS 当前提供的主屏。测试覆盖了扩展桌面；镜像显示、Sidecar 和不同显示驱动仍需分别实机验收。

## 独立交互与共享数据

各屏的点击展开、悬停、移出后收起，以及录屏、番茄钟等面板的临时设置状态互相独立。副屏断开或关闭多屏开关不会重置保留下来的主屏窗口。

任务监测、音乐、计时器、番茄钟、闹钟和备忘录继续共用同一份数据，不为每个显示器启动额外的音频检测或任务轮询。计时完成、解锁问候等主动提醒继续使用原有共享提醒逻辑，手动展开状态不会相互传播。

有刘海时避让真实安全区域；无刘海屏幕的紧凑岛在中央预留约 205 pt 的纯黑区域，文字和图标排列在两侧。展开面板按各屏可用宽度安排分页。录屏设置关闭「包含灵动岛」时，会排除所有灵动岛窗口。

## 新电脑安装

下载 Release 附件中的应用 ZIP，解压后将 `DynamicIsland.app` 拖入 Applications，再从应用程序打开。预构建应用运行不需要 Xcode、Python、Node 或本项目源码。屏幕检测本身不需要录屏权限；录屏、麦克风、Music 自动化和歌词辅助功能仍由系统按实际功能管理权限。

本次提供 Apple silicon / arm64 预览版，声明最低 macOS 26.5。另台全新 Mac、最低系统和 Intel 尚未完成实机验收；可选 AI 与设备集成仍依赖目标机器上对应软件和数据。

## 自动检查

`zsh scripts/run-multi-display-tests.sh` 使用合成显示器和隐藏的应用窗口，检查独立展开、共享数据、屏幕重排与重连、纯黑中央区域，以及副屏开关的默认值、即时更新、主屏切换和重启保存。测试不截取用户屏幕、不进行真实录屏，也不修改用户的真实偏好。
